# As frustrações esportivas e financeiras do Flamengo

Página para embed sobre o que o Flamengo deixou de arrecadar em 2026: vices da Supercopa do Brasil e da Recopa Sul-Americana, eliminação para o Vitória na Copa do Brasil (meta era a semifinal) e venda frustrada de Plata. Total: R$ 105,5 milhões. Explica também por que a semifinal da Libertadores não compensa a perda.

- Página: `index.html` (publicada via GitHub Pages em https://igorsiqueirahub.github.io/flamengo-frustracoes/)
- Código do iframe para a matéria: `embed.html`

O iframe tem altura fixa (900 px, até 85% da altura da tela) e barra de rolagem própria; não precisa de script.

Valores estimados com base em reportagens; dólar convertido pela cotação de 23/10/2026.
